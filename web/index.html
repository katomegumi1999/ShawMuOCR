功能特性

为效率而生的全能 OCR

从截图识别到跨设备同步，覆盖日常文字处理全场景

截图 OCR 识别

一键快捷键截取屏幕区域，自动识别文字并复制到剪贴板。支持多显示器、混合 DPI 环境，1:1 物理像素精准捕获。

Alt+Z 触发

高级截图标注

内置功能丰富的标注编辑器：矩形、椭圆、箭头、画笔、高亮、文字、编号标记、马赛克、高斯模糊，支持撤销/重做与钉选到桌面。

Alt+C 触发

即时屏幕翻译

框选任意屏幕区域，即时获取 OCR + 翻译结果。支持百度、Google Cloud NMT v2、OpenAI 兼容接口（GPT-4o-mini、DeepSeek、Qwen 等）。

Alt+T 触发

CPU/GPU 双轨引擎

CPU 模式使用 x64 AVX2/SIMD 向量化推理；GPU 模式通过 Vulkan 计算着色器并行加速。智能检测显卡类型，支持独显/核显手动切换。

零拷贝直通

批量 OCR & PDF

批量导入图片和多页 PDF 文件，并行处理，导出为 TXT / JSON / Markdown 格式。内置 HTTP REST API 服务器，方便自动化集成。

REST API

跨设备剪贴板同步

基于 Rust 高性能引擎 (MuClip)，XChaCha20-Poly1305 端到端加密，DH 密钥协商。支持大文件分块传输与快捷短语浮窗。

使用流程

一个快捷键，完成所有操作

无需切换窗口、无需上传图片。按下快捷键，框选屏幕区域，文字即刻出现在剪贴板中。内核级全局热键，睡眠唤醒后依然有效。

  • Win32 RegisterHotKey 内核级热键，零 CPU 开销
  • GDI+ 多显示器 DPI 自适应截图
  • 识别完成自动复制，气泡通知反馈
  • 截图钉选到桌面，1:1 像素完美叠加
  • 支持 PNG / JPG / WEBP / BMP 多格式保存
