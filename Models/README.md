# 外部模型存放目录 (External Models Directory)

小沐 OCR **默认已将官方高精度 PP-OCRv6 推理模型内嵌于程序集**中，开箱即用，无需在此目录放置任何文件即可完整运行。

---

## 选用外部自定义 PaddleOCR 模型

如果您需要使用自定义训练或不同语言的 Paddle 模型，可按以下步骤配置：

1. **新建子文件夹**：例如在此目录下新建 `v6/` 文件夹（即 `models/v6/`）；
2. **放置 ONNX 模型文件**：
   - 文字检测模型：命名中包含 `det`（如 `ch_PP-OCRv6_det_infer.onnx`）
   - 文字识别模型：命名中包含 `rec`（如 `ch_PP-OCRv6_rec_infer.onnx`）
   - （选填）方向分类模型：命名中包含 `cls`（如 `ch_ppocr_mobile_v2.0_cls_infer.onnx`，缺省将复用内置官方分类模型）
   - （选填）自定义字典文件：命名为 `dict.txt` 或 `*.txt`（缺省将复用内置官方中文字典）
3. **启用识别**：
   - 打开软件【系统设置】➔【OCR 模型设置】➔ 勾选“开启扫描”，即可在下拉列表中直接选用您的外部模型。
